# UI/UE 规范文档 - Equity View

**文档状态**: 初版
**更新日期**: 2026-03-13
**设计参考**: TradingView 股票图表平台

---

## 1. 整体设计风格

### 1.1 设计主题

本项目采用 **深色主题（Dark Theme）** 为主的设计风格，符合金融数据分析工具的通用规范。

| 属性 | 值 |
|------|-----|
| 主题模式 | 深色主题（默认） |
| 设计参考 | TradingView |
| 配色方案 | 暗色系背景 + 鲜艳的数据色 |
| 视觉风格 | 现代、简洁、专业 |

### 1.2 色彩体系

#### 1.2.1 背景颜色

```
主背景：#131722（最暗，用于页面底色）
面板背景：#1e222d（次暗，用于侧边栏和工具栏）
交互背景：#2a2e39（悬停状态）
选中背景：#363a45（激活状态）
```

#### 1.2.2 文字颜色

```
主文字：#D1D4DC（标题、重要信息）
次文字：#787B86（辅助信息、标签）
辅助文字：#565969（说明性文本）
链接/可交互：#2962FF（蓝色链接色）
```

#### 1.2.3 数据颜色（K 线图）

```
上涨蜡烛：#089981（青色/绿色）
下跌蜡烛：#F23645（红色）
阳线实体：#089981
阴线实体：#F23645
涨跌幅度显示：+ 号用上涨色，- 号用下跌色
```

#### 1.2.4 功能按钮颜色

```
主操作按钮：#2962FF（蓝色系）
卖出相关：#8B0000（暗红色）
买入相关：#006400（深绿色）
悬停状态：亮度 +15%
激活状态：亮度 -10%
```

### 1.3 排版规范

#### 字体家族

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Oxygen, Ubuntu, Cantarell, "Open Sans", "Helvetica Neue", sans-serif;
```

#### 字号层级

| 层级 | 字号 | 字重 | 使用场景 |
|------|------|------|----------|
| H1 | 24px | 600 | 页面主标题 |
| H2 | 20px | 600 | 板块标题 |
| H3 | 18px | 500 | 卡片/面板标题 |
| Body | 14px | 400 | 正文内容 |
| Small | 12px | 400 | 辅助说明、标签 |
| XSmall | 10-11px | 400 | 坐标轴标注、图表数据 |

#### 字重层级

```
600 (SemiBold) - 标题、强调内容
500 (Medium)   - 次级标题、按钮文本
400 (Regular)  - 常规正文

```

采用 **4px 基础栅格系统**：

| 间距级别 | Pixel | 使用场景 |

| xs | 4px | 元素内边距、紧凑布局 |

## 3. 组件设计规范

### 3.1 K 线图（Candlestick Chart）

#### 蜡烛样式

| 属性 | 上涨蜡烛 | 下跌蜡烛 |
|------|----------|----------|
| 实体颜色 | #089981 | #F23645 |
| 边框色 | 同实体色 | 同实体色 |
| 上影线 | 实线，宽度 1-2px | 同上 |
| 下影线 | 实线，宽度 1-2px | 同上 |
| 填充模式 | 实心填充 | 实心填充 |

#### 交互状态

```
悬停蜡烛：放大显示详细数据浮层
十字准星：鼠标移动时的十字线和价格标签对齐网格

浮层内容格式:
┌──────────────┐
│ 2026-03-13   │ ← 日期（白色）
│ O: 5.48      │ ← 开盘价
│ H: 6.02      │ ← 最高价
│ L: 5.40      │ ← 最低价
│ C: 6.02      │ ← 收盘价
│ V: 181.37M   │ ← 成交量（绿色数字）
└──────────────┘

浮层样式：
- 背景色：#1e222d
- 文字颜色：白色为主，成交量用涨跌色
- 边框：细线 #363a45
```

## 4. 交互设计规范

### 4.1 鼠标悬停效果

| 元素类型 | 悬停反馈 |
|----------|----------|
| 可点击按钮 | 背景亮度 +15% |
| K 线蜡烛 | 显示数据浮层，十字准星跟随 |
| 菜单项 | 背景色 #2a2e39 |
| 链接/图标 | 文字颜色变为 #2962FF |

### 4.2 图表交互功能

#### 鼠标操作

| 操作 | 功能 |
|------|------|
| 滚轮滚动 | 缩放时间轴（放大/缩小 K 线数量） |
| 拖拽 | 平移图表，查看不同时间段数据 |
| 悬停蜡烛 | 显示该日期详细 OHLCV 数据浮层 |
| 十字准星 | 跟随鼠标移动的价格十字线 |

#### 绘图工具交互

```
选择绘图工具后：
1. 光标变为十字形
2. 在主图区域点击确定起点
3. 拖动到目标位置确定终点
4. 双击或按 Enter 确认绘制
5. 按 Esc 取消操作

已绘制的线条：
- 可拖拽调整端点
- 悬停显示编辑选项
- 右键删除或修改属性
```

### 4.3 弹窗/下拉菜单交互

#### 自选表管理

```
点击"+"按钮 → 弹出添加股票搜索框
输入股票代码 → 实时搜索结果推荐
选择结果 → 添加到自选列表

点击"✕"按钮 → 移除对应股票

点击右上角"┊⚣"图标 → 更多操作菜单
- 导出自选
- 排序设置
```

#### 下拉菜单规范

```
背景色：#1e222d
边框：1px solid #363a45
阴影：0 2px 8px rgba(0,0,0,0.3)
内边距：8px
选项间距：4-8px

悬停状态：背景色 #2a2e39
分隔线：1px solid #2a2e39 (between items)
```

### 4.4 响应式设计

#### 断点定义

| 断点名称 | 宽度范围 | 布局调整说明 |
|----------|----------|--------------|
| XL/Desktop | ≥1440px | 标准桌面布局 |
| LG/Tablet | 1024-1439px | 适当压缩间距 |

## 5. 图表辅助功能

### 5.1 网格系统

```
主网格线：颜色 #2a2e39，粗细 1px
次网格线：颜色 #2a2e39，粗细 0.5px（透明度更低）

垂直网格：对应 K 线日期标记
水平网格：对应价格刻度对齐
```

### 5.2 价格轴和日期轴

**Y 轴价格标签：**
- 字号：11-12px
- 颜色：#787B86
- 对齐方式：右对齐或居中对齐
- 格式：保留两位小数，如 "6.02"

**X 轴日期标签：**
- 字号：11-12px
- 颜色：#787B86
- 显示密度：根据缩放级别动态调整（月/季/年）
- 格式："Aug", "Sep", "Oct"... (月份简写) or "2026" (年份)

### 5.3 成交量柱状图

```
对齐方式：与上方 K 线精确垂直对齐
颜色:
  - 上涨日：#089981（半透明）
  - 下跌日：#F23645（半透明）
透明度：0.6-0.7
```

### 5.4 技术指标叠加（扩展）

| 指标类型 | 显示位置 | 线宽建议 |
|----------|----------|----------|
| MA/Moving Average | 主图，彩色线条 | 2px |
| MACD | K 线图下方独立面板 | - |
| RSI | 独立面板（0-100） | 2-3px |
| Bollinger Bands | 主图覆盖 K 线 | 1.5px |

## 6. 数据展示规范

### 6.1 数字格式化规则

| 数据类型 | 格式示例 | 说明 |
|----------|----------|------|
| 股价/价格 | 6.02 CNY | 两位小数 + 货币符号 |
| 涨跌幅（绝对值）| +0.55 / -0.55 | 正数加 + 号，负数固定 - 号 |
| 涨跌幅百分比 | +10.05% / -3.24% | 两位小数 + %号，颜色区分涨跌 |
| 成交量（百万）| 181.37M | 一位小数 + "M"后缀 |
| 市值（十亿）| 15.45B | 两位小数 + "B"后缀 |

### 6.2 状态标识

```
市场状态：
- Market closed → 灰色小字 "Market closed"
- Market open   → 绿色圆点 + "Market open"（带实时闪烁）
- Pre-market    → 橙色标记
- After-hours   → 紫色标记

更新时效说明:
Last update at 15:00 GMT+8 → 灰色小字，对齐显示最后更新时间
```

### 6.3 行业分类展示

```
格式示例:
Health Technology · Biotechnology

样式：
- 字号：12-14px
- 颜色：#787B86
- 分隔符：中间点 "·"，用于区分行业层级
```

## 7. 无障碍设计（Accessibility）

### 7.1 对比度要求

| 组合 | 对比度 | 状态 |
|------|--------|------|
| 主文字/背景 | ≥ 4.5:1 | WCAG AA 达标 |
| 辅助文字/背景 | ≥ 3:1 | WCAG AA 达标 |
| 涨跌色/白色 | ≥ 4.5:1 | 符合标准 |

### 7.2 键盘导航支持

```
Tab 键：依次聚焦可交互元素
Enter/Space：激活当前聚焦元素
Esc：关闭弹窗/取消操作
↑↓←→：图表区域内导航（缩放和平移快捷键）
```

### 7.3 屏幕阅读器优化

- 为所有图标按钮提供 aria-label
- K 线图使用 ARIA 角色 description
- 动态数据更新使用 live region

## 10. 错误和异常状态处理

### 10.1 数据加载状态

```
加载中:
- 显示骨架屏（Skeleton Loading）或 旋转指示器
- 背景色：#2a2e39 的占位区块

格式示例:
┌──────────────┐
│    ▒▒▒      │ ← 数据加载占位符
│    ████     │
└──────────────┘
```

### 10.2 错误状态

| 场景 | UI 表现 |
|------|---------|
| 股票代码不存在 | Toast 提示 + 输入框红边 |
| 网络请求失败 | "数据加载失败" 消息 + 重试按钮 |
| 无历史数据 | "无可用数据" 占位图 + 说明文字 |

### 10.3 空状态

```
自选表为空:
┌─────────────────────┐
│                         │
│      [图标]               │
│   No Stocks Added         │
│    Click '+' to add       │
│                         │
└─────────────────────┘

样式：
- 颜色：#787B86
- 字号：14px
- 居中显示
```
